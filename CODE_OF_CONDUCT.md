# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

Positive behavior: empathy, respect, constructive feedback.  
Unacceptable: harassment, publishing private data, encouraging unauthorized security testing or attacks.

## Enforcement

Report concerns privately to the maintainer (see SECURITY.md). Maintainers may remove contributions or ban violators.
