# Security Policy

## Reporting

Report vulnerabilities **privately** (GitHub Security Advisories preferred). Do not open public issues for credential leaks or weaponizable attack details.

## Project rules

- This kit is for **authorized** defensive audits only.
- Do not commit OpenRouter keys, customer reports, or live credentials.
- Mode 7 red-team requires `AUTHORIZED=yes` and `authorization.md` — do not bypass.
